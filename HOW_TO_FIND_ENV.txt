============================================================
WHY YOU CANNOT SEE THE .env FILE ON YOUR PHONE
============================================================

The file is named ".env" (it starts with a DOT).

On almost every mobile file manager (Files by Google, Samsung My Files,
iOS Files, etc.) files that start with a dot are HIDDEN by default.

HOW TO SEE IT:
1. Open your file manager
2. Look for "Show hidden files" / "Display hidden files" / three-dot menu
3. Turn that option ON
4. You will then see .env, .env.example, .gitignore, etc.

ALTERNATIVE: I have also created a visible copy called "env-copy.txt"
in this folder. You can rename it to .env after copying to your server.

MYSQL CONNECTION WAS BROKEN – NOW FIXED

That is why you kept getting "cannot connect" errors on registration.

- server.js            → added (was missing; package.json expects it)
- scripts/setup-database.js will also need SSL when you run it

Registration should work once you deploy these fixed files to your server
(Render, Railway, VPS, etc.) and restart the app.
